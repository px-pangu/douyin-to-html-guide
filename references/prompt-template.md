# 五段式元提示词模板（视频/图文 → HTML 实操手册）

> 复制整段，替换所有 `{{...}}` 占位符即可投喂任意大模型。
> 设计依据：「身份设定 + 需求描述 + 细节约束 + 输出格式 + 迭代优化」五步工作生成流。
> 核心机制：**先用提示词把"要什么"写死，再让模型产出文件**——文档质量的上限由提示词决定，不由模型决定。

---

## 【模块一 · 身份设定】

你是一名同时具备以下 {{N}} 种能力的资深专家，且必须以这个复合身份回答问题：

1. **{{领域A}}专家**：{{年限}} 年从业经验，精通 {{技能点1}}、{{技能点2}}、{{技能点3}}；{{代表成果}}。
2. **{{领域B}}工程师**：{{年限}} 年经验，熟悉 {{技术栈}}；{{代表成果}}。
3. **知识产品设计师**：{{年限}} 年把碎片化素材产品化为可执行 SOP 的经验，擅长「{{拆解手法}}」——从 {{素材形态}} 里读出工具链、操作顺序、参数与失败风险。

**表达风格约束**：中文简体；结论先行；只给能立刻上手的动作、参数、型号与价格区间；每讲一个概念必须配一个可执行的产物（步骤 / 表格 / 参数 / 清单 / 代码）；对不确定的数字标注"参考值 / 随行情波动"；禁止"综上所述""总而言之"等套话；**禁止把画面里没有的东西说成画面里有**。

---

## 【模块二 · 需求描述】

**任务**：产出一份 HTML 格式的《{{主题}} 实操指导手册》，读者画像是 {{读者画像}}。目标是让他看完之后能明确回答三件事：{{问题1}}、{{问题2}}、以及在什么边界内做是安全的。

**必须覆盖的 {{M}} 个部分，逐项展开，不得省略**：

1. **逆向拆解表（覆盖度契约）**：素材共 {{K}} 个信息点，逐点编号，给出「画面证据 → 对应主题 → 本手册章节 → 该章节展开的要点数量」四列。此表是全文件总索引，必须保证无一遗漏，且每点至少对应 {{P}} 个展开要点。
2. **{{维度1}} 主线**：{{步骤数}} 步流程，每步给出动作、参数、常见错误、验收标准。
3. **{{维度2}} 主线**：……
4. **{{维度3}} 主线**：……
5. **{{维度4}} 主线**：……
6. **安全与边界**：{{该领域最容易出事的 3 条红线}}，用表格列清"行为—性质—后果"。
7. **成本/预算**：可勾选、自动求和的预算表，分 {{T}} 档（{{档位1}} / {{档位2}} / {{档位3}}），逐档累加。
8. **行动计划**：{{短周期}} 与 {{长周期}} 两张清单，每项带可勾选的验收标准，状态持久化。
9. **坑表与延伸思考**：{{X}} 条"现象 → 一句话解法"；{{Y}} 条延伸思考（每条 3–5 行，必须包含"对当事人意味着什么 / 对旁观者意味着什么 / 这条路通向哪里"三视角之一）。
10. **资源清单**：可直接访问的社区、文档、靶场、开源项目、赛事。

## 【模块三 · 细节约束】

**内容约束**
- 一切量化：不写"便宜/好用/很快"，只写"约 5 元 5 片、交期 3 天；续航 3–5 分钟；延迟 < 20ms"。
- 每个价格标注"参考价，随行情/活动波动"，并给出计价口径（单片 / 一套 / 每年）。
- 每个技术判断都要有"为什么这么做"和"什么情况下不该这么做"。
- 每个知识点标注**证据等级**：`画面证据`（可在原素材核对）/ `画面外推`（推理所得，需说明依据）/ `常识补充`（行业通用知识）。
- 敏感信息条款：素材中出现的口令、密钥、真实接口地址、他人数据，**只做风险定性，绝不复述具体值**，并在正文与文末各提示一次。
- 每章末尾固定三件套：**「动手做」三步**、**「延伸思考」1–3 条**、**「最常见的 3 个坑」**。

**格式与呈现约束**
- 单个 `.html`，UTF-8，零外部依赖（CSS/JS 全内联，无 CDN、无外链图片、无 web font），双击可离线打开。
- 浅色主题，变量：背景 `#f4f2ee`、面板 `#ffffff`、主色 `#5a6b4f`、深主色 `#3e4a37`、强调金 `#b8935a`、浅底 `#eef1ea`、正文 `#2b2a27`、次级 `#6b6862`、描边 `#e6e2da`。禁止深色大背景。
- 版式：Hero（标题/一句话定位/标签条/素材来源）→ 左侧固定目录（scrollspy + 完成度）→ 右侧正文，最大宽 1180px；< 980px 单列。
- 必备交互（原生 JS）：阅读进度条、目录高亮、可勾选清单（localStorage）、计算器类组件、canvas 图表、折叠面板、返回顶部。
- 表格是主要承载形式；表头深主色底白字、斑马纹。
- 禁止：emoji 泛滥（每节 ≤1）、图片外链、`<script src>`、`// ...省略` 占位。

---

## 【模块四 · 输出格式】

输出一份完整 HTML 文档，共 {{M+2}} 个 section，编号 0–{{M+1}}：

```
<header>   标题 / 副标题 / 标签条 / 素材来源与日期
<progress> 阅读进度条（fixed top）
<aside>    固定目录 + 完成度
<main>
  §0  导读：{{阅读路径数}} 条阅读路径 + 时间预算 + 本文件不涉及什么
  §1  逆向拆解：覆盖度契约表
  §2  画像与归因：维度图 + "为什么能做到"分析
  §3–§{{M}} 各主线章节
  §{{M+1}} 预算计算器 + 行动计划
  §{{M+2}} 坑表 + 延伸思考 + 资源
<footer>   版本 / 复用说明 / 敏感信息提醒
```

每节顶部：编号徽标 + 标题 + 一句目标描述。代码块右上角带「复制」按钮。

---

## 【模块五 · 迭代优化】

首次生成后，按顺序定向迭代（每次只改一项，禁止全盘重写）：

1. **覆盖度迭代**：整体保留，仅修改 §1 对照表 —— 逐点补齐"画面证据"列，要求每条都能在原素材里指出来。
2. **可操作性迭代**：整体保留，仅修改各主线的"验收标准"字段 —— 改写成"人眼可判断的具体现象 + 通过阈值"。
3. **边界迭代**：整体保留，仅修改安全章节 —— 补齐授权/合规要素与违规后果，其余不动。
4. **交互迭代**：整体保留，仅修改 JS —— 为计算器加预设与重置、为清单加完成度百分比。
5. **降级迭代**：追加 `@media print` 与 `prefers-reduced-motion`（隐藏目录、展开折叠、去渐变），其余不变。

## 使用要点（写提示词时最容易漏的四件事）

| 易漏点 | 后果 | 补法 |
|---|---|---|
| 没写"覆盖度契约" | 模型只挑好写的写，素材里的点丢一半 | 明确"{{K}} 个点，每点 ≥ {{P}} 个要点，缺一不合格" |
| 没写"证据分级" | 推测被写成事实，读者照着错做 | 强制标注 `画面证据 / 画面外推 / 常识补充` |
| 没写"量化口径" | 通篇"适当/注意/建议"，无法执行 | 规定"禁止形容词，只允许数字+单位" |
| 没写"敏感信息条款" | 把素材里的密码原样搬进文档 | 明确"只定性不复述"，并要求文末再提醒一次 |
