# HTML 实操手册 · 视觉与交互规范

这份规范是「视频知识 → HTML 手册」流水线的产物标准。目标是：**像一本能打印的书，同时像一个能用的小工具**。

---

## 1. 技术底线

| 项 | 要求 |
|---|---|
| 文件 | 单个 `.html`，UTF-8，双击可离线打开 |
| 依赖 | 零：无 CDN、无 `<script src>`、无外链图片、无 web font |
| 图形 | CSS / 内联 SVG / `<canvas>` 手绘，不引图表库 |
| 图标 | 用文字符号（↑ ✓ + −）或 CSS 画，不用 emoji 堆砌 |
| 兼容 | 现代浏览器；`< 980px` 单列；`@media print` 可打印 |

---

## 2. 设计变量

```css
--bg:#f4f2ee;        /* 页面底色 */
--panel:#fff;        /* 卡片底色 */
--ink:#2b2a27;       /* 正文 */
--ink-soft:#6b6862;  /* 次级文字 */
--accent:#5a6b4f;    /* 主色（墨绿） */
--accent-deep:#3e4a37;
--accent-light:#eef1ea;
--gold:#b8935a;      /* 强调金：数字、标签、分隔 */
--line:#e6e2da;      /* 描边 */
--radius:14px;
--shadow:0 6px 24px rgba(60,55,45,.07);
```

字体：`"PingFang SC","Microsoft YaHei","Segoe UI",sans-serif`；代码 `Consolas,"Cascadia Code",monospace`。
行高 1.75–1.8（长文可读性的关键，别用 1.5）。

---

## 3. 版式骨架

```
<header>   Hero：章节标签 / H1（主色高亮关键词）/ 一段定位 / 素材来源行 / 六维 chips
<div id=progress>  顶部 3px 进度条
<div class=layout>   grid: 236px | 1fr，gap 44px
  <aside>   sticky，目录 a 列表 + 完成度小卡
  <main>
    <section id=s0>  sec-head(编号方块 + h2) + p.sec-goal + 正文
    ...
<footer>   版本 / 来源 / 免责
<button id=totop>
```

- 内容最大宽 **1180px**，正文不要铺满屏（超过 70 字符/行阅读疲劳）。
- 章节必带 `scroll-margin-top`，否则锚点跳转会被顶部遮住。
- `aside` 在 `<980px` 变为顶部横向 chip 列表，隐藏完成度卡。

## 4. 必备组件（缺一个就扣分）

| 组件 | 实现要点 |
|---|---|
| 阅读进度条 | `scrollHeight - innerHeight` 比例，`position:fixed` |
| 目录 scrollspy | 滚动时取最后一个 `offsetTop <= scrollY+120` 的 section |
| 编号方块 | 44×44 圆角 12，主色底白字，`box-shadow` 提浮 |
| 步骤卡 `.step-card` | 左侧 4px 主色边；每行左侧金色小标签（动作/参数/错误/验收） |
| 表格 | 表头深主色底白字、`tbody tr:nth-child(even)` 斑马纹、`overflow-x:auto` 包裹 |
| 提示框 `.callout` | 浅绿底 + 左 4px 主色边；`.warn` 变浅棕底 + 深棕字 |
| 代码块 | 深底 `#2f332c`、顶部标题条、右上「复制」按钮（`navigator.clipboard` + `execCommand` 兜底） |
| 折叠 `details` | summary 前置 +/− 圆形徽标，展开后 `content:"−"` |
| 三件套 `.trio` | 三列：动手做（主色）/ 延伸思考（金）/ 三个坑（棕） |
| 计算器 | 复选框 + `data-price` + 实时合计 + 档位预设 + localStorage |
| 清单 | 复选框 + `closest('.task-item').classList.toggle('done')` + 完成度百分比 |
| canvas 图表 | `devicePixelRatio` 缩放，`style.maxWidth=100%`，否则移动端溢出 |
| 返回顶部 | 滚动 > 600px 时 `.show` |
| **认知升维卡 `.ladder`** | 卡片左缘金色 3px 边；顶部一行：梯子名（加粗主色）+ 右侧锚点徽标 `起于画面 ⑤`；正文四行小表：`观点 / 边界（灰字，斜体）/ 动作（主色底浅块）`；行距 1.8 |
| **三级跳表** | 三行 L1/L2/L3，每行给「问什么 / 产出 / 靠什么证伪」三列；L3 行用金色左边线强调 |
| **认知速查块** | 金底浅块，8–10 句判断句，编号排列，供打印贴墙；每条 ≤ 30 字，必须是判断不是描述 |

## 5. 内容组织规范

1. **每章固定三件套**：动手做（3 步，可当天执行）/ 延伸思考（1–3 条，每条有观点而非复述）/ 三个坑（现象 + 一句话解法）。
2. **表格优先**：凡是"多方案对比 / 参数 / 阈值 / 故障 / 预算"一律上表格，不要写成段落。
3. **证据标注**：`画面证据` 用 callout 顶部统一交代；外推内容在括号里注明「画面外推」。
4. **数字必须带单位与口径**：`约 5 元 / 5 片 / 3 天`，不要只写"很便宜"。
5. **每节开头一句 `sec-goal`**：告诉读者"读完这节你能干什么"，不是"本节介绍了…"。
6. **认知升维章固定五段**：三级跳表 → 六把梯子卡片（每把 1–3 条）→ 「这本书没告诉你的事」3 条 →
   「五年后回头看」3 条 → 一页认知速查（8–10 句判断句）。位置在实操章之后、速查卡之前。
   梯子卡按「时间尺 / 尺度 / 主体 / 反事实 / 上层 / 成本」固定顺序排列，不重排。

---

## 6. 禁止清单

- ❌ 深色大背景（这是文档，不是落地页）
- ❌ 渐变滥用、玻璃拟态、发光边框
- ❌ 大段无格式文本（超过 5 行没有列表/表格/分点）
- ❌ emoji 当图标用满屏
- ❌ `// ...省略` / `<!-- 略 -->` 占位
- ❌ 任何需要联网才能显示的资源
- ❌ 把素材里的真实凭据、他人数据、接口地址原样写进文档
- ❌ 认知章出现鸡汤句（`愿你 / 热爱可抵 / 格局决定 / 只要你肯 / 未来可期 / 双向奔赴`）
- ❌ 认知章只给结论不给推理链，或只谈态度不谈结构
- ❌ 认知章重复实操章已经讲过的操作步骤

## 7. 交付前 10 项自检

1. 断开网络，双击打开，样式与交互都正常？
2. 每个目录锚点都能跳到正确位置，且标题不被遮挡？
3. 所有表格在手机宽度下能横向滚动，不撑破页面？
4. 勾选几个清单项，刷新页面后状态还在？
5. 计算器的合计与手算一致？三档预设数量正确？
6. 控制台无报错？
7. 打印预览（Ctrl+P）下目录隐藏、折叠内容展开、无大面积空白？
8. 全文搜 `password / secret / token`，确认没有真实值？
9. **认知章存在吗**？每条思考都有锚点、有边界、有可迁移动作吗？L3 ≥ 8 条吗？
10. **全文搜 `愿你|热爱可抵|格局决定|只要你肯|未来可期|双向奔赴`**，命中即删？
